# 🫶 CareerAI – AI-Powered Career Mentor

## 🚀 Overview

CareerAI is an AI-powered career intelligence platform that helps students and professionals transform their resumes into personalized career growth plans.

Using Google's Gemini AI, CareerAI analyzes resumes, identifies skill gaps, evaluates ATS readiness, generates learning roadmaps, and prepares users for interviews.

The platform acts as a supportive AI mentor that guides users toward their dream careers with actionable insights and personalized recommendations.

---

## ✨ Features

### 📄 Resume Analysis

Upload your resume and instantly receive AI-powered career insights.

### 🧠 Skill Extraction

Automatically identifies technical and professional skills from resumes.

### 🎯 Career Gap Analysis

Compares current skills against a target career role and highlights missing skills.

### 🛣️ Personalized Learning Roadmap

Generates a structured learning plan to help users reach their career goals.

### 🎤 AI Interview Preparation

Creates role-specific interview questions ranging from beginner to advanced levels.

### 📊 ATS Resume Score

Evaluates resume readiness for Applicant Tracking Systems (ATS) and provides improvement suggestions.

### 🚀 Career Readiness Dashboard

Displays skills, ATS score, recommendations, and career progress in an easy-to-understand dashboard.

## ⚙️ Installation

### Clone Repository

git clone <repository-url>

cd career-mentor

### Install Dependencies

pip install -r requirements.txt

### Create Environment File

Create a `.env` file:

GEMINI_API_KEY=YOUR_API_KEY

### Run Application

python -m streamlit run app.py
